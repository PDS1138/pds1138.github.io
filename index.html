AEROSPACE SYSTEMS ENGINEERING · 1987–1991

F-CK-1 Flight-Control Built-In Test Architecture

System Testability · Fault Detection · Embedded Software · Aircraft Integration

Developed the architecture and detailed software requirements for a high-coverage preflight Built-In Test (BIT) of the digital flight-control system. Performed end-to-end testability and tolerance analysis from processor and memory functions through LRU interfaces, aircraft sensors, and actuators.

Identified fault-detection coverage gaps that drove new hardware stimulus requirements to equipment vendors; adapted and optimized Lockheed’s BIT interpreter for F-CK-1 needs; and developed a software model of the Analog Independent Backup Unit to accelerate test-case development.

3 · ARCHITECTURE FINDING

Coverage analysis drove changes outside the software

The end-to-end analysis exposed actuator-related failure modes that the original architecture could not adequately stimulate or detect. Closing the gap required new vendor hardware capability—not simply more software.
