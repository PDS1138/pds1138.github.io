Flight-Control Verification Engineering

JAS-39 Gripen
Flight Controls Built-In Test Verification & FMET

Fault Injection • FMET • Built-In Test Verification • Integrated System Test
1991–1993 | BAE Systems • Sweden

Developed flight-control-system Failure Modes and Effects Test (FMET) procedures and performed pilot-in-the-loop testing in an integrated iron-bird test environment using injected fault conditions to verify flight-control behavior under failure. In a separate activity, created a Built-In Test verification plan and injected hardware failures to evaluate BIT fault detection and isolation without pilot-in-the-loop.

4.Verification Focus

Behavior under failure and maintenance-level fault awareness

System-Level Failure Response

FMET demonstrated that the integrated flight-control system behaved correctly when specified failure conditions were introduced.

Built-In Test Effectiveness

BIT verification demonstrated that deliberately injected hardware failures were detected and isolated by the implemented diagnostic function.

The work emphasized verification of implemented behavior — not ownership of the underlying aircraft safety analysis or original flight-control architecture.
